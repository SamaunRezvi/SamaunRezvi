# Architecture

The profile `README.md` is static markup. Everything dynamic is either fetched live by an image URL or generated by a scheduled workflow and committed back as a static SVG.

## Live badges

Profile views, followers, stars, tech badges, the typing animation and the divider lines are image URLs rendered on request by external services. They store no data in this repository.

## Generated cards

`.github/scripts/generate_profile_cards.py` queries the GitHub GraphQL API and writes these files:

| File | Content |
| --- | --- |
| `assets/top-languages.svg` | Top languages by repo size |
| `assets/commit-stats.svg` | Stars, commits, PRs, issues |
| `assets/productive-time.svg` | Commits per hour of day |
| `assets/contribution-activity.svg` | Last 31 days of activity |
| `assets/streak-stats.svg` | Total, current and longest streak |

## Profile details card

`assets/profile-details.svg` is fetched from a public card service by the same workflow. If the service is unavailable the step exits cleanly and the cached file is kept.

## 3D contribution graph

`3d-contrib.yml` runs `yoshi389111/github-profile-3d-contrib` with `.github/3d-contrib-settings.json` and commits the result to `profile-3d-contrib/`. The README embeds `profile-custom.svg`.

## Snake animation

`snake.yml` renders the contribution grid snake with `Platane/snk` and publishes it to the `output` branch. The README references the files there through raw URLs.
