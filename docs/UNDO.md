# Undoing the card audit changes

Before the card audit the repository was tagged `backup/before-card-audit-2026-11-10`.

## See what changed

```bash
git log --oneline backup/before-card-audit-2026-11-10..main
```

## Undo one change (keeps history, safest)

```bash
git revert <commit>
git push origin main
```

Each change is its own commit: activity graph fix, productive time fix, PR/issue totals, failure isolation, card recolour, profile summary recolour, snake palette and the Latest Public Projects section.

## Go back to exactly the old version

```bash
git switch -c old-version backup/before-card-audit-2026-11-10   # inspect it first on a branch
git reset --hard backup/before-card-audit-2026-11-10             # then reset main to it
git push --force-with-lease origin main                          # rewrites history
```

The cards are regenerated by the `Refresh Profile Cards` workflow, so after going back, run that workflow once to rebuild the old assets.
