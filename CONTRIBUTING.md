# Contributing

This is a personal profile repository, so outside changes are rarely needed. If you spot a bug, open an issue.

For the owner's own changes:

1. Change one thing at a time.
2. Run `python tools/check.py`.
3. Commit with a short conventional message (`feat:`, `fix:`, `docs:`, `style:`, `chore:`).
4. Do not edit files in `assets/` or `profile-3d-contrib/` by hand. Edit `.github/cards-content.json` and run the matching tool instead (see `docs/CONTENT.md`).
